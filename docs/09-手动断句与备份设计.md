# 手动断句与媒体备份设计

状态：手动断句已在 1.0.7 测试版实现；备份格式和导入导出尚未实现。

## 手动断句

- 用户在播放器时间轴框选 A/B 区间，保存为当前媒体的「手动断句」轨。可以重复框选，句子按起始时间排列并编号，原有 AI 和导入字幕轨继续保留。
- 点击句子按选定模式播放：单句无限循环、单句指定遍数、顺序播放、列表循环。默认单句无限循环，不提供随机播放。
- 句子保存在本地数据库，起止时间以毫秒记录。可以通过字幕编辑界面修改或删除。
- 精听列表支持左滑编辑或删除句子，删除需确认。折叠精听区会停止句子循环并从媒体开头播放；离开或切换媒体后重新打开时从零开始，句子和 A/B 选区保留。

## 备份的用户操作

- 单个导出：从某条媒体的菜单导出，包含该音视频和其全部字幕轨、句子及播放位置等媒体设置。
- 全部导出：支持媒体库内全部条目，以及用户授权扫描后选择设备上其他视频和音频。只有媒体库中的文件才可能已有 EchoLoop 断句；未加入媒体库的文件可与空轨一起备份。用户需在导出前看到数量和预计体积。
- 导入：通过系统文件选择器选一个备份包，列出包含的媒体并允许选择单个、多个或全部导入。默认新增副本，不覆盖现有媒体或字幕；导入的媒体文件存放在应用私有持久目录，界面提示卸载应用会删除这些副本。
- 系统文件选择器决定导出保存位置，支持移动到其他设备。复制原始媒体内容，不能依赖 `content://` URI 或本机绝对路径。

## 备份包

使用版本化 `.echoloop` ZIP 容器，保存 UTF-8 `manifest.json` 和按内部随机 ID 命名的媒体文件。清单只包含跨设备所需的媒体名称、类型、时长、大小、播放和循环设置、字幕轨信息与句子时间及文本；不包含 API Key、签名密钥、缩略图缓存、设备路径或数据库内部 ID。

每个媒体记录文件大小和 SHA-256，导入时校验。所有音视频以流式方式读写，不把整个视频放入内存。明确处理读取权限失效、存储空间不足、用户取消、中途断电以及无法读取的文件，不能把失败导出报告为成功。备份包可能很大，显示进度及正在处理的文件。

## 一致性和安全

- 严格校验格式版本、条目、时间范围、大小及校验值；拒绝绝对路径、`..`、重复内部文件名和未知引用，避免路径穿越和静默丢数据。
- 导入先解压到新建的隔离目录，检查文件和清单；用户选择后再导入。数据库写入使用事务并为媒体和字幕重新分配 ID，失败清理本次临时文件，不触碰已有条目。
- 不把整个数据库或应用设置直接导出，避免泄露无关个人信息和覆盖目标设备设置。重复导入默认建立独立副本，后续可增加用户明确选择的去重策略。
- 备份功能应覆盖文件 URI、SAF `content://` URI、部分权限失效、大文件、零句子媒体、多个字幕轨、单项与全部选择、损坏/截断 ZIP、空间不足与进程中断。需在真实 Android 设备验证。
