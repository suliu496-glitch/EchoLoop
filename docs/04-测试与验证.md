# Testing and verification / 测试与验证

## 中文

在项目根目录执行：

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

当前单元测试覆盖字幕解析、字幕边界吸附、播放时间推进、循环逻辑、时间轴边界和屏幕适配。Android 设备上还应手动检查：导入/播放音视频、字幕导入和编辑、AI 服务配置与转写、单句循环与自动推进、息屏后台播放及通知栏控制。

AI 转写测试会把媒体内容上传到配置的服务商。使用测试素材前请确认拥有相应权限，并留意服务商可能产生的费用。

## English

Run these commands from the repository root:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

The unit tests cover subtitle parsing, subtitle-boundary snapping, playback timing, loop behavior, timeline edges, and screen adaptation. On an Android device, also verify media import/playback, subtitle import/editing, AI provider configuration and transcription, sentence looping and auto-advance, background playback with the screen off, and notification controls.

AI transcription sends media audio to the configured provider. Use test media only when you have the necessary rights, and check whether the provider charges for requests.
