# Build and release / 构建与发布

## 中文

### 环境要求

- Flutter stable，Dart SDK 3.12.2 或更高版本
- Android SDK 和 Android arm64 构建工具
- JDK 17
- 首次拉取依赖和 Gradle 原生播放依赖时需要网络

Flutter 会在 Android 工程中生成本机 `local.properties`。该文件只保存本机 SDK 路径，已由 `.gitignore` 排除。

### 获取依赖与检查

```sh
flutter pub get
flutter analyze
flutter test
```

### 构建 arm64 APK

```sh
flutter build apk --release --target-platform android-arm64
```

产物位于 `build/app/outputs/flutter-apk/app-release.apk`。当前项目最低支持 Android 8.0（API 26），只生成 `arm64-v8a` APK。

没有提供 `android/key.properties` 时，工程会使用 Android 调试签名来生成可本机安装的 Release 构建。公开发布前请创建自己的上传密钥；不要复用或提交其他人的密钥。

### 配置自己的签名密钥

在本机创建密钥文件，并将签名配置写入 `android/key.properties`：

```properties
storeFile=keystore/echoloop-upload.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=echoloop
keyPassword=YOUR_KEY_PASSWORD
```

`storeFile` 路径相对于 `android/`。例如上面的值对应 `android/keystore/echoloop-upload.jks`。`android/key.properties`、`android/keystore/`、JKS 和 keystore 文件均被 Git 忽略。把密码放入本机安全存储，并妥善备份密钥；丢失签名密钥可能使既有应用无法通过原渠道升级。

### 原生播放依赖

Android 构建通过 `media_kit_libs_android_video` 获取上游 libmpv 原生播放依赖。构建时需要访问上游发布文件；项目仓库不包含预编译的 `.so` 或 APK。许可说明见 [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。

## English

### Requirements

- Flutter stable with Dart SDK 3.12.2 or later
- Android SDK and Android arm64 build tools
- JDK 17
- Network access for the first dependency resolution and native playback artifact download

Flutter generates `android/local.properties` for the local SDK path. Git ignores this machine-specific file.

### Resolve dependencies and check the source

```sh
flutter pub get
flutter analyze
flutter test
```

### Build an arm64 APK

```sh
flutter build apk --release --target-platform android-arm64
```

The output is `build/app/outputs/flutter-apk/app-release.apk`. The minimum Android version is Android 8.0 (API 26), and the current build produces an `arm64-v8a` APK.

If `android/key.properties` is absent, the project uses the Android debug key for a locally installable Release build. Create your own upload key before distributing an APK; never reuse or commit someone else's key.

### Configure your signing key

Create a key locally, then put its settings in the ignored file `android/key.properties`:

```properties
storeFile=keystore/echoloop-upload.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=echoloop
keyPassword=YOUR_KEY_PASSWORD
```

`storeFile` is relative to `android/`; the example points to `android/keystore/echoloop-upload.jks`. Git ignores `android/key.properties`, `android/keystore/`, JKS files, and keystore files. Store passwords securely and keep a backup of the key. Losing the signing key can prevent upgrades through the same distribution channel.

### Native playback dependency

Android builds obtain the upstream libmpv playback dependency through `media_kit_libs_android_video`. Gradle needs access to the upstream release artifact. This repository does not include prebuilt `.so` files or APKs. See [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) for licensing information.
