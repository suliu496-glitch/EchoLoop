# Contributing to EchoLoop

## 中文

欢迎提交问题和改进。提交代码前请先搜索已有 issue，说明复现步骤、预期结果和实际结果；问题报告不要包含 API Key、签名密钥、私人媒体或日志中的个人信息。

建议的本地检查：

```sh
flutter pub get
flutter analyze
flutter test
```

请让每个提交聚焦一个改动，补充必要的测试和文档，并遵守项目现有的 Dart 格式与命名风格。涉及 AI 识别时，请使用你有权处理的测试音视频。

提交贡献即表示你有权按项目的 GNU GPL-3.0-only 许可证发布这些改动。

## English

Issues and improvements are welcome. Search existing issues first and include reproduction steps, expected behavior, and actual behavior. Do not include API keys, signing keys, private media, or personal information from logs in public reports.

Run these checks before submitting code:

```sh
flutter pub get
flutter analyze
flutter test
```

Keep each change focused, add tests and documentation where appropriate, and follow the project's existing Dart formatting and naming style. Use only audio/video you are authorized to process when working on AI transcription.

By submitting a contribution, you confirm that you have the right to release it under the project's GNU GPL-3.0-only license.
